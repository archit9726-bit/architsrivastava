Tips
- .jpg, .jpeg, .png or .webp all work (e.g. fns.png).
- Use lowercase names exactly as above — most web hosts care about capitals.
- Best size: a wide image, about 2400 × 600 px (4:1), under ~500 KB.
- A cover in this folder wins over the cover set in js/content.js.
  To go back, delete or rename the file here.
- To choose which part of the image shows, or to show it whole, use the
  cover settings in js/content.js (coverPosition, coverFit, coverHeight, coverBg).
- Refresh the browser after adding a file.
